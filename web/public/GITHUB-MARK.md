# GitHub mark

[GitHub Brand Toolkit](https://brand.github.com/foundations/logo), distributed in
[the official logo archive](https://brand.github.com/GitHub_Logos.zip).

GitHub and the Invertocat logo are trademarks of GitHub, Inc. These marks identify
the navigation link to the Wakeit GitHub repository; they are not Wakeit branding.
